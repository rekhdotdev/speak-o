# Freeze the first public beta

Speak-O 0.1.0 is a Chrome 124+ public beta comprising ElevenLabs BYOK, `chrome.tts`, generic Article extraction, an X Articles Site Adapter, Selection reading, original-page highlighting, floating controls, and an options page; provider expansion, PDFs, OCR, reader overlays, downloads, playlists, history, sync, accounts, subscriptions, incognito, other browsers, and mobile are explicitly deferred so the first release can establish reliable extraction, aligned speech, and an auditable accountless security boundary.
