# Extract semantic Articles with strict source mapping

Speak-O first honors an explicit Selection, then uses a recognized Site Adapter such as X Articles, and otherwise applies Mozilla Readability to a cloned document as an Article-confidence gate before selecting a conservative semantic root (`article`, `[role="article"]`, or `main`) on the live Source Page. It validates visible content and maps narratable spans directly from that live root to original text nodes. It rejects materially incomplete or ambiguous mappings and falls back to Selection instead of guessing highlight positions; this trades some Readability-selected-tree precision for stable live ranges, reliable activation, and recovery from pages that would otherwise remain stuck while finding an Article. New Site Adapters remain justified only by fixture-backed failures.
