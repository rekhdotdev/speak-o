# Freeze the first release

_Superseded in its provider-expansion boundary by [ADR-0014](0014-add-speechify-as-an-explicit-provider.md)._

Speak-O 0.1.0 was the initial Chrome 124+ release comprising ElevenLabs BYOK, `chrome.tts`, generic Article extraction, an X Articles Site Adapter, Selection reading, original-page highlighting, floating controls, and an options page; provider expansion, PDFs, OCR, reader overlays, downloads, playlists, history, sync, accounts, subscriptions, incognito, other browsers, and mobile were explicitly deferred so the first release could establish reliable extraction, aligned speech, and an auditable accountless security boundary.
