# Add Speechify as an explicit provider

Speak-O offers Chrome Voice, ElevenLabs, and Speechify as explicit Speech Provider choices, with the chosen provider fixed for the lifetime of a Reading Session unless the user manually switches to Browser Voice Mode. ElevenLabs and Speechify keep independent Provider Credentials, optional host permissions, metadata, Models, and Voices; existing `cloud` preferences and descriptors migrate deterministically to ElevenLabs. Both Cloud providers retain the bounded Generation Window and confirmation-before-retry rules, while their adapters preserve provider-native behavior: ElevenLabs keeps timestamped WebSocket generation and word highlighting when alignment is valid, and Speechify uses MP3 sentence streams with sentence highlighting. Speak-O never silently fails over between providers.
